## Design

```python
class Colorizer(Protocol):
    def colorize(self, panel: Path, atlas: Path | None, output: Path) -> ColorizeRecord: ...

@dataclass
class ColorizeRecord:
    status: str            # ok | error
    request_id: str | None
    output: Path | None
    latency_s: float
    requested_size: tuple[int, int]
    error: str | None
```

- Size policy (user-confirmed): request the resolution **closest to the panel's
  original size** with both axes multiples of 16 — per axis,
  `max(16, round(x/16)*16)` (Python half-even rounding, clamped to a minimum of 16;
  e.g. 340×500 → 336×496, 345×505 → 352×512, 10×10 → 16×16). Colorize at that
  resolution; stitching resizes the output back to the exact panel box (original
  dimensions). No upscaling to a fixed target — tiny panels stay tiny and may
  colorize poorly; record this in the quality notes (README, task_0010).
- Request: multipart fields `prompt`, `width`, `height`, `num_inference_steps`
  (default 20), `guidance_scale` (4.0), `lora_scale` (1.0), `seed`, `output_format`;
  files: `images` ×2 = [panel, atlas] (or `images` ×1 = [panel] if no atlas, pending
  the empty-detection policy). Response is raw image bytes.
- Per-call record includes timings, requested size, sha256 of inputs/output; cost is
  recorded as $0 per call (self-hosted) + electricity note in the manifest (same
  wording as the research method's `LOCAL_PRICING`).
- Optional `--endpoint` check: warn when the server is unreachable with a clear
  message (fail fast, one connection test at step start).

## Tests (`test_colorizer.py`)

- `fake_flux_server` decodes the multipart body and verifies the client sent
  `images` in order [panel, atlas], correct width/height (multiples of 16), prompt
  containing `mngclranm`, and the settings fields; returns a tinted image.
- Client writes the returned bytes to `output` and the record has `status=ok`.
- Size policy: nearest-multiple-of-16 unit tests (340×500 → 336×496,
  345×505 → 352×512, 600×900 → 608×896, degenerate 1×1 and 10×10 → 16×16;
  half-rounding edge 24×24 → 32×32).
- Server error (HTTP 500) → `status=error`, no crash.
- Atlas-less call (policy b) sends only one image.
