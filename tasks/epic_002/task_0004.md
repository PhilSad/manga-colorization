# Task 0004 — Handle full-page art and cap oversized colorization requests

> **Status: 📋 PLANNED**
>
> Depends on task 0001; may be implemented in parallel with tasks 0002–0003.

## Goal

Colorize meaningful pages for which YOLO returns no framed panels, and avoid sending
exceptionally large spread-sized images to FLUX at native resolution.

## Context

In the V1 volume run, p006 is a full-page illustration with no panel frame. YOLO
returned zero boxes, so the page stayed black and white. The p004-p005 spread was
treated as one 2896×2256 panel and required 71.7 seconds—about 30% of total FLUX
latency for the five-page run.

Both cases can be addressed deterministically without a new paid service.

## Files

- `pipeline_v1/steps/panels.py` — blank-page check and synthetic full-page box.
- `pipeline_v1/config.py` — `--full-page-fallback`, blank threshold, and a maximum
  colorization megapixel/side policy.
- `pipeline_v1/colorizer.py` — aspect-preserving bounded FLUX request size.
- `pipeline_v1/steps/stitch.py` — verify full-page and resized-panel placement.
- Panel, size-policy, stitching, and end-to-end tests.

## Design

When zero panels are detected:

1. measure whether the page is effectively blank using a conservative deterministic
   rule that does not reject sparse line art like p006;
2. if meaningful ink exists and fallback is enabled, emit one synthetic box covering
   the full canvas and mark its provenance as `full-page-fallback`;
3. if effectively blank, record a deliberate skip without a FLUX call.

For oversized inputs, scale both dimensions down proportionally to a configurable
maximum pixel count, then round to multiples of 16. Never upscale ordinary panels.
Record original crop size, requested size, scale factor, and the applied limit.

Evaluate at least two bounded sizes on the spread with the same seed, judging fine
line/text preservation against latency and energy. Select the largest cap that gives
no visible regression in the representative output.

## Tests

- Sparse full-page art produces one full-page panel; a blank page produces none.
- Normal YOLO detections never receive an additional synthetic box.
- Size capping preserves aspect ratio within rounding tolerance and uses multiples
  of 16.
- Stitching a capped full-page output returns exactly the source canvas dimensions.

## Acceptance criteria

- [ ] The p006 evaluation page is colorized without paid detection calls.
- [ ] The spread's FLUX latency is materially lower with no unacceptable visual
      regression recorded in the evaluation.
- [ ] Ordinary panel request sizes and outputs are unchanged.
- [ ] Manifest, README, and tests cover both fallback decisions and size limits.
- [ ] Commit with a meaningful message.
