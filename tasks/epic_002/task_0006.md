## Goal

Run the same representative inputs used for V1, compare quality and cost using the
fixed evaluation contract, and document V1.1 with enough provenance to reproduce the
result.

## Context

V1's five-page run processed 18 panels with 18 OpenRouter calls for `$0.00137551`
and 18 self-hosted FLUX calls in 358 seconds. V1.1 should improve identity accuracy,
canonical palette adherence, full-page coverage, and oversized-input efficiency
without increasing the paid baseline.

## Runs

1. Offline test suite and mock end-to-end run.
2. Fixed failure-set experiment from task 0001 with ground-truth identities and a
   fixed seed.
3. Volume-1 five-page comparison using exactly `--skip-first 3 --limit 5`.
4. Chapter-134 one-page smoke for incomplete-reference behavior.
5. Optional verification-enabled comparison only if task 0005 was implemented.

Every invocation creates a fresh timestamped output directory. Never overwrite the
V1 runs or compare different page sets as though they were equivalent.

## Measurements

- character precision/recall and uncertain fallback count;
- canonical-color adherence and line/text preservation on the fixed cases;
- pages/panels colorized, including the p006 full-page fallback;
- OpenRouter calls, tokens, measured USD cost, and cost per page;
- FLUX original/retry calls, latency, requested megapixels, and electricity estimate;
- wall time and the spread latency before/after size capping;
- subjective failure cases with representative annotated images.

## Cost guardrails

- Character detection for the five-page comparison must not exceed V1's measured
  `$0.00137551` without an explicitly documented reason.
- Verification remains disabled in the default comparison and, if tested, is
  reported as a separate optional cost.
- Prompt/profile experiments use ground-truth character labels so they incur no
  repeated detection cost.
- Large experiments stop when the fixed failure set shows no improvement.
