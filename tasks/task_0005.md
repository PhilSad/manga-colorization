# Task 0005 — Filtered reference atlas builder

## Goal

Implement the atlas builder used by stage 4: given the characters detected in a panel,
build a labelled reference atlas containing **only those characters'** reference images
(from `data/refs/`), in the same visual style as the existing colorization methods
(labelled grid).

## Context

The colorization step must receive "an atlas composed only of the detected characters"
(idea step 4) so the model uses the right canonical colors and is not distracted by
irrelevant references. This is a port of `build_reference_atlas` from
`research/colorization_methods/flux-2-klein-9b-base-lora-edit-sequential/run.py`
(360×480 cells, 36 px label strip, DejaVu bold, JPEG quality 94), parameterized to a
subset of refs.

- Empty-set policy: **pending the user's answer** (question 5). Default implemented

## Tests (`test_atlas.py`)

- `refs_for_characters`: tmp refs dir with a few webp files; correct file selected,
  `_reference` preferred over `_anime_profile`, unknown character → warning + skipped.
- `build_labelled_atlas`: output is a JPEG of the expected dimensions
  (`columns × 360` × `rows × 480` + labels), 1 ref → 1×1 grid, 4 refs → 2×2 grid;
  labels drawn (check via pixel sampling is optional — assert the refs list order maps
  to grid positions through the recorded layout helper if added).
- Round-trip: every canonical name in the input list has its label present in the
  atlas (verify via a small OCR-free check: export the (label → cell) mapping from the
  builder for tests, or sample non-white pixels per cell).
