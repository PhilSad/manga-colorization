# Task 0007 — Stitching colorized panels back onto the original page

> **Status: ✅ DONE** (implemented, tests green, committed as `07f9106`)

## Goal

Implement stage 5: paste each colorized panel onto the original black-and-white page
at the position recorded in `1_panels/<page>/panels.json`, writing the final pages to
`4_stitched/`. Everything outside the panel boxes stays untouched (black & white).

## Context

The final step of the idea ("une fois la case colorier, elle est stitch a la page
original a la bonne position"). The colorized panel from the FLUX server is at the
nearest-multiple-of-16 resolution (task_0006); it must be resized back to the exact
panel box size — the panel's original dimension, from `panels.json` — before pasting.
The source page is never modified — the stitched page is a new file.

## Files

- `pipeline_v1/stitching.py` — pure functions.
- `pipeline_v1/steps/stitch.py` — step: for each page, load original + panels.json +
  colorized panels → write `4_stitched/<page_stem>.png`.
- `pipeline_v1/tests/test_stitching.py`.

- Convert page to RGB, paste each colorized panel resized to the box size
  (`(x2-x1) x (y2-y1)`), clipped to page bounds.
- Optional `inset` (config, default 0): shrink the paste target by N px on each side
  to preserve panel borders if the detector box includes them — default 0 per the
  current design, revisit after a real run.
- Order of pasting: reading order (does not matter visually, panels don't overlap;
  defensive: sort by panel_index).

## Tests (`test_stitching.py`)

- Synthetic page (white + gray rectangles at known boxes) + synthetic colorized panels
  (solid distinct colors): stitched result has the expected color inside each box and
  the original grayscale pixels outside the boxes (pixel-level assertions).
- Panel resized correctly: colorized 682×1024 panel pasted into a non-16-multiple box
  (e.g., 340×500) has exactly the box dimensions.
- Box partially outside page bounds → clipped paste, no exception.
- Empty colorized list → returns an unchanged copy of the page.
