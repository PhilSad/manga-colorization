## Goal

Make the pipeline discoverable and reproducible per repo conventions: write
`pipeline_v1/README.md`, add a pipeline entry to `methods.md` (new "Pipelines"
section), run one **real** page end-to-end (real YOLO weights + real OpenRouter

## Context

AGENTS.md requires: every new method/pipeline must be added to `methods.md` in the
same change that adds its implementation; outputs and cost information must be
reflected there; measured vs estimated must be labeled; representative output runs
linked. The pipeline combines the character-detection (companion) and colorization
research into one orchestrator, so it gets its own `methods.md` row (or section) with
links to both underlying methods.
